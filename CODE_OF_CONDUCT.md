# Code of Conduct

Eunomia is a technical project and we want it to be a place where people can disagree about
code without it getting personal.

## Expected behaviour

- Be respectful and assume good faith. Critique the change, not the person.
- Keep discussion on topic and in the open, in issues and pull requests.
- Accept review feedback gracefully, and give it kindly and specifically.
- Welcome newcomers; explain instead of dismissing.

## Unacceptable behaviour

- Harassment, insults, discrimination or personal attacks of any kind.
- Publishing someone else's private information.
- Spam, or promotion unrelated to the project.
- Anything else that would reasonably be seen as inappropriate in a professional setting.

## Scope and enforcement

This applies to all project spaces: the repository, its issues, pull requests and
discussions. Maintainers may edit or remove contributions that break these rules, and may
warn, temporarily restrict or ban a participant.

To report a problem, email **l3ekirerdem@gmail.com**. Security vulnerabilities are handled
separately, see [`SECURITY.md`](SECURITY.md).
